## 🚀 Projects

### 🟩 [MCStat.org](https://mcstat.org) — Minecraft Server & Player Platform
> The most-visited project I run. A real-time Minecraft server list with live player counts, uptime history, vote rankings, ping latency and per-country breakdowns — plus **50K+ player profiles** with name/skin history, a cape gallery, a forum, and a self-serve ad marketplace. A [Bukkit/proxy plugin](https://github.com/mcstatorg/MCStat-Plugin) streams signed telemetry (sessions, TPS, votes) straight from server owners' machines.

`Next.js` `TypeScript` `PostgreSQL` `Prisma` `Redis` `Ping Worker` · **6,732 servers · 227K players online · 250K daily peak**

### 🎵 [Beatra](https://beatra.app) — Advanced Discord Music Bot
> Multi-platform music streaming across Discord, web, desktop and Discord Activities. Plays YouTube, YouTube Music, Spotify, Apple Music, Deezer, SoundCloud, Tidal, Audius and Qobuz. 24/7 mode, smart autoplay, audio filters, playlists, a custom-bot tenant system, listening analytics and **Beatra Wrapped**. Premium from $1.49/mo.

`Discord.js v14` `Node.js` `React` `Electron` `MongoDB` `Redis` `Lavalink` · **32,826 servers · 2.1M+ users · 99% uptime**

### 💬 [JustDiscord](https://justdiscord.org) — Discord Server & Bot List
> A Discord discovery platform built around trust: every listing carries a score out of 5 with reviews that explain the score, ownership is verified through Discord itself, and sponsored placements are always labelled. Also the largest free Discord emoji/sticker library I host, plus an hourly bump system, a review system, and a public API with vote webhooks.

`Next.js` `TypeScript` `PostgreSQL` `Prisma` `Edge Cache` `i18n` · **8.1K servers · 8.2K bots · 91K emojis · 5.4K stickers · 2.1K packs**

### 🛒 [Codeshare](https://codeshare.me) — Digital Marketplace for Developers

Escrow protection on every order, verified sellers, instant auto-delivery, YouTube-subscriber gating, real-time chat, and a [developer CLI](https://github.com/codeshareme/codeshare-cli) that version-controls snippets from the terminal.

`Next.js` `TypeScript` `PostgreSQL` `Node.js` `Payments` · **10K+ users · 13.9K+ snippets · 30+ categories**
